I built a responsive redesign of Tactyqal Labs around an interactive eight-week build notebook and the students’ projects. The homepage and public journal use the same database-backed publishing workflow. Editors can save drafts, preview, publish, edit and delete articles. The repository includes the API, migrations, setup instructions, and a staged plan for moving the existing WordPress content into the new system.
